# Alpha cover resources

Drop transparent PNG/WebP/AVIF subject images in this folder.

The demo cover automatically discovers files here at runtime and prefers filenames containing words such as `cover`, `portrait`, `person`, `founder`, or `subject`. The first matching image becomes the demo cover subject and is preloaded with high fetch priority.

Examples:

- `cover-founder-01.png`
- `portrait-entrepreneur-02.webp`
- `subject-creative-director.avif`
