# XPOMAG — Art Direction Pass 01

This build art-directs the cover and pages 02–11 as the first reusable editorial system pass.

## Typography system
The app now discovers curated local files from `public/resources/fonts/assets` at runtime via `/api/editorial-fonts` and falls back safely when the folder is absent.

Curated roles:
- Instrument Serif — high-impact editorial serif / pull quotes
- Newsreader — long-form editorial body
- Big Shoulders Display — condensed display headlines
- Bricolage Grotesque — contemporary grotesk / subheads
- IBM Plex Sans — interface / utility text

## Reusable hierarchy
The magazine remains composed from:
- primitive design elements: text, label, divider, image, stack, grid
- editorial modules: portrait feature, pull-quote box, data stat, pulse card, signal row
- page sections: hero, headline, body, list, aside
- page layouts: feature-offset-left, article-classic, contents-index, advert-full
- issue composition: the ordered 64-page page model
