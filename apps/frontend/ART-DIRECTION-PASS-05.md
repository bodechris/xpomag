# XPOMAG Art Direction — Pass 05

## Pages 35–42: Art, culture and after hours

This pass moves the magazine into a deliberately more expressive cultural chapter without abandoning the reusable composition system.

### New reusable page systems
- `culturePosterPage` — dominant portrait + poster headline + editorial copy + quote block.
- `cultureGuidePage` — high-impact guide with large portrait, title field and six reusable place modules.
- `notebookCulturePage` — image-led editor's notebook with four compact observation cards.
- `afterHoursFeaturePage` — cinematic dark feature with oversized subject, glow field, body copy and pull quote.
- `afterHoursModesPage` — editorial nightlife guide built from four reusable behaviour modules.
- `afterWorkAdvertPage` — full-page concept ad using the same design-element hierarchy.

### Whitespace rule
Whitespace is intentional only when it provides pause, emphasis, luxury or scale. Otherwise the page must carry useful editorial content, a visual anchor, metadata, imagery or a functional interaction.

### Composition principle
Design elements -> modules -> page sections -> page layouts -> issue.

The pages are intentionally not clones: the reusable elements allow the chapter to move between poster, guide, notebook and cinematic modes while remaining recognisably XPOMAG.
