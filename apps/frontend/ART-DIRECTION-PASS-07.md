# XPOMAG Art Direction Pass 07 — Pages 51–58

This pass pushes the wellness / running / weekend / utility chapter into a faster, more kinetic visual language while preserving the reusable magazine composition system.

## Reusable page systems added
- `wellnessFeaturePage()` — oversized editorial headline + full-height cutout portrait + two-column story copy + metric + quote.
- `runClubPage()` — running-community feature with a dominant portrait and stacked guide modules.
- `itineraryPage()` — time-based city itinerary with a large visual anchor and reusable timeline cards.
- `weekendPosterPage()` — poster-like weekend checklist with 12 compact saveable prompts and a full-height image.
- `eventsCalendarPage()` — event-calendar system with date blocks, venue metadata and a large supporting image.
- `xpomag12Page()` — editor's notebook / curated-save system for twelve items.
- `threadAdvertPage()` — full-page commercial campaign with dominant image, oversized type and branded graphic field.

## Whitespace rule
Empty space remains only where it creates hierarchy, energy, pause, luxury or visual focus. Otherwise the page is filled with meaningful imagery, editorial copy, utility modules, metadata or graphic structure.
